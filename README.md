## ⚔️ Engagement Preparation

A match can be segmented into preparation states:

```text
LOOT
  ↓
LOADOUT
  ↓
RESOURCE CHECK
  ↓
ENGAGEMENT
  ↓
RESOURCE CONSUMPTION
  ↓
REPLENISH
  ↓
NEXT ENGAGEMENT
```

This creates a historical view of how inventory decisions affected later fights.
